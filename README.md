<h2>About</h2>

<p>
  <strong>Coderr</strong> is a service marketplace where customers can browse
  offers, place orders and review business users.
</p>

<p>
  The frontend was originally provided by
  <strong>Developer Akademie</strong> as part of the Backend Developer curriculum.
  I forked and adapted it for integration with my own
  <strong>Django REST Framework backend</strong>.
</p>

<blockquote>
  My main implementation work for this project is the backend.
  This repository contains the provided frontend adapted for integration
  and portfolio presentation.
</blockquote>

<h2>Tech Stack</h2>

<p>
  <strong>HTML5</strong> •
  <strong>CSS3</strong> •
  <strong>Vanilla JavaScript</strong>
</p>

<h2>Setup</h2>

<h3>1. Clone the repository</h3>

<pre><code>git clone https://github.com/JuliaKeller13/Coderr_frontend.git
cd Coderr_frontend</code></pre>

<h3>2. Start the backend</h3>

<p>
  Follow the setup instructions in my
  <a href="https://github.com/JuliaKeller13/coderr_backend">
    Coderr Backend repository
  </a>.
</p>

<p>Backend:</p>

<pre><code>http://127.0.0.1:8000/</code></pre>

<h3>3. Start the frontend</h3>

<p>
  Open the project in Visual Studio Code and launch the root
  <code>index.html</code> with <strong>Live Server</strong>.
</p>

<p>Frontend:</p>

<pre><code>http://127.0.0.1:5500/</code></pre>

<h2>API Connection</h2>

<p>
  For local development, the frontend connects to:
</p>

<pre><code>http://127.0.0.1:8000/api/</code></pre>

<p>
  Authentication and application data are handled by the corresponding
  Django REST API.
</p>
